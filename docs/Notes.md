An application that allows a team to track their work on one share board, they can create items and see what else other team member is working.

Feature Requirements:

- MVP: require a UI to show the dashboard, submit the new working item and the item they plan to work on soon. 

- MVP: User need to be authenticated to get into the dashboard. Assuming everyone wull have the same permission.

- MVP: Work Item need to have a title, description, assigned_to, status: [New, Planning, In progress, finished]

- MVP: Need to be able to assign item to either the user himself or someone else on the team. The item can be reassigned throughout the lifecycle of the work item, anybody can reassign.

Out of Scope:
- Nice to have Work Item Planning: is   

Non functional requirements:

- 50 thousands team, 5m items, 500 concurrent views/editors in a single team.
